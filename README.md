# E-commerce Data Analytics Project

## Overview
Built an ELT pipeline using BigQuery to analyze user behavior and conversion funnel.

## Data Sources
- Clickstream events
- Orders table

## Architecture
Python → BigQuery → SQL transformations → Analysis

## Key Analyses
- Funnel conversion rates
- Payer vs non-payer behavior
- Retention analysis

## Key Insights
- X% drop from view to cart
- Y% of users purchase without add_to_cart
